Google Alerts Setup — CAN-MACRO Strategic Dashboard
====================================================

Go to https://www.google.com/alerts and create each alert below.

Settings for EACH alert:
  - How often: As-it-happens
  - Sources: News
  - Language: English (or French for Quebec alerts)
  - Region: Canada
  - How many: All results
  - Deliver to: RSS feed  <-- IMPORTANT: select "RSS feed", NOT email

After creating each alert, copy the RSS feed URL and paste it into
rss_feeds.json under the "google_alerts" category, replacing
"PASTE_FEED_URL_HERE" for the matching entry. Then set "enabled": true.
