Editorial Policy

All content on The Lagging Indicator is factual reporting. The platform presents data, context, and connections between indicators and projects. It does not take positions, make recommendations, or express opinions.

  • Every factual claim cites a specific source
  • Indicator values reference the exact StatCan table or source API
  • Project data includes evidence URLs for independent verification
  • No language implying events are good, bad, promising, or worrying
  • Conditional language for projections ("if rates hold..." not "rates will...")

Data Validation

A 7-rule validation layer runs before every data export:

  1. Range check — values within plausible bounds for each indicator class
  2. Delta check — period-over-period changes within historical thresholds
  3. Null consistency — if value is null, change must also be null
  4. Period recency — reference period within expected freshness window
  5. Change verification — stored change independently recomputed from values
  6. Duplicate detection — flags identical values across unrelated indicators
  7. Unit verification — cross-checks stored units against expected units

Indicators that fail validation are flagged as "under review" rather than displayed with incorrect values.

Known Limitations

  • Productivity Growth data is sparse for some economies (US, China, EU)
  • Some commodity prices may show stale data when yfinance returns cached values
  • Project classification is under development — most projects currently tagged as Greenfield
  • Provincial GDP data uses annual figures (StatCan does not publish provincial quarterly GDP)
  • The construction price index (Table 18-10-0135) has been discontinued by Statistics Canada

The Lagging Indicator User Guide

What is this?

A weekly intelligence briefing covering Canadian capital projects, economic indicators, policy, and markets. Updated every Monday. All content is factual reporting with sourced data.

Briefing Archive

Past briefings are accessible via the Archive tab. Each briefing covers one week's developments.

Project Database

The Projects tab shows capital projects tracked across all provinces. Filter by province, sector, or status. Click a row to expand details, evidence sources, and status history.

  • Value — Estimated project cost in CAD. "Unconfirmed" means value not yet verified.
  • Confidence — 0.0-1.0 score based on evidence sources, government backing, and verification. Decays if not re-confirmed in 30+ days.
  • Timeline — Color bar showing project lifecycle: grey=proposed, blue=construction, green=complete, amber=on hold.
  • GOV badge — Project has at least one government source.

Data Explorer & V-Codes

Search StatCan indicators by keyword. Each V-code links directly to the StatCan table. Categories: Labour Market, GDP, Construction, Housing, Prices, Trade, Rates, Energy, Demographics.
