  <name>Task 1: Rewrite update_dashboard.py and project_sync.py to use db.py</name>
  <files>update_dashboard.py, project_sync.py</files>
  <action>
  **update_dashboard.py — the main pipeline entry point:**

  1. **Remove Firebase initialization block** (lines ~123-133): Delete `import firebase_admin`, `from firebase_admin import credentials, firestore`, the `firebase_admin.initialize_app()` block, and `db = firestore.client()`.
  2. **Add SQLite initialization:** `from db import init_db, get_db` at top. Replace `db = firestore.client()` with `conn = init_db()`. Use `conn` everywhere `db` was used.
  3. **Update PipelineRunLogger:** Change `PipelineRunLogger(db, run_type=...)` to `PipelineRunLogger(conn=conn, run_type=...)`.
  4. **Update Tavily tracking:** Change `set_tracking_db(db)` to `set_tracking_db(conn)` (or whatever Plan 03 renamed it to). Change `can_use_tavily(db)` to `can_use_tavily()`.
  5. **Update all db.collection() calls:** Search for every `db.collection(` in the file. Replace with appropriate db.py function calls:
     - `db.collection("projects")` reads -> `get_projects(conn, ...)` or `get_all_projects(conn)`
     - `db.collection("dashboard_state").document(X).set(Y)` -> `save_dashboard_state(conn, X, Y)`
     - `db.collection("indicator_history")` -> `save_indicator(conn, ...)` / `get_indicators(conn, ...)`
     - `db.collection("weekly_briefings")` -> `save_briefing(conn, ...)` / `get_latest_briefing(conn)`
     - `db.collection("trend_snapshots")` -> `save_trend_snapshot(conn, ...)`
  6. **Pass conn to module functions:** Where update_dashboard.py calls functions from other modules that need DB access, pass `conn` instead of `db`. For example: `upsert_projects(conn, payload['provinces'])` instead of `upsert_projects(db, ...)`.
  7. **Remove `from google.cloud.firestore_v1 import ...`** if present.

  **project_sync.py — project upsert logic:**

  1. **Remove any Firestore-specific code.** Currently project_sync.py takes a `db` (Firestore client) parameter and calls `db.collection("projects")`.
  2. **Refactor upsert_projects() and upsert_flat_projects():**
     - These functions receive raw project data from discovery modules, normalize it, and write to DB.
     - Replace all `db.collection("projects").document(key).get()` / `.set()` / `.update()` calls with `from db import upsert_project, get_project`.
     - The core merge logic (evidence, status, confidence) is now in db.py's `upsert_project()`, so project_sync.py becomes a thin wrapper that normalizes incoming data and calls `db.upsert_project(conn, normalized_project)`.
     - Keep helper functions (`normalize_key`, `fuzzy_match`, `_parse_value_millions`, `_to_numeric_confidence`) — these are pure logic with no DB dependency.
  3. **Update function signatures:** `upsert_projects(conn, provinces_data)` and `upsert_flat_projects(conn, projects_list)` — accept sqlite3.Connection instead of Firestore client.

  Ensure no `firebase_admin`, `google.cloud.firestore`, or `.collection(` references remain in either file.
  </action>
