  <action>
  These 8 backfill scripts are utility scripts run occasionally (not part of the weekly pipeline). Each one currently initializes its own firebase_admin connection. Apply this pattern to all 8 files:

  1. **Remove the Firebase init block.** Every one of these files has a variation of:
     ```python
     import firebase_admin
     from firebase_admin import credentials, firestore
     if not firebase_admin._apps:
         cred = credentials.Certificate('serviceAccountKey.json')
         firebase_admin.initialize_app(cred)
     db = firestore.client()
     ```
     Delete this entire block.

  2. **Replace with db.py init:**
     ```python
     from db import init_db, get_db, upsert_project, get_all_projects, save_indicator, get_indicators
     conn = init_db()
     ```
     Import only the specific functions each script needs.

  3. **Replace Firestore operations:**
     - `db.collection("projects").stream()` -> `get_all_projects(conn)`
     - `db.collection("projects").document(id).get()` -> `get_project(conn, norm_key)`
     - `db.collection("projects").document(id).update(data)` -> `upsert_project(conn, merged_data)`
     - `db.collection("indicator_history").document(id).set(data)` -> `save_indicator(conn, data)` (auto-remaps Firestore field names)
     - `db.collection("timeseries").document(id).set(data)` -> `save_dashboard_state(conn, f"ts_{id}", data)` or dedicated timeseries save function

  4. **Handle Firestore-specific patterns:**
     - `doc.to_dict()` -> already a dict from db.py
     - `doc.id` -> use the dict's id/norm_key field
     - `doc.exists` -> check if return is None
     - `firestore.SERVER_TIMESTAMP` -> `datetime.utcnow().isoformat()`
     - `ArrayUnion([...])` -> read, append, write back (db.py handles this in upsert_project)

  **Note on backfill scripts:** Many of these are one-time scripts that may never run again. The migration is still needed to satisfy DB-07 (no firebase_admin imports in any .py file). If a script is truly obsolete, add a comment at the top noting it was migrated for completeness but may not be needed post-SQLite migration.
