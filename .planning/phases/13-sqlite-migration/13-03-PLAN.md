  Rewrite PipelineRunLogger to use db.py instead of Firestore. Key changes:

  1. **Remove all Firestore imports:** Delete `from google.cloud.firestore_v1 import ArrayUnion, Increment` and any firebase_admin references.
  2. **Import db.py:** `from db import get_db, save_pipeline_run, update_pipeline_run`
  3. **`__init__`:** Accept optional `conn` parameter (sqlite3.Connection). If not provided, call `get_db()`.
  4. **`start()`:** Build the same run document dict, call `save_pipeline_run(conn, doc_data)` which returns the row ID. Store `self._run_id` instead of `self._doc_ref`.

  8. **`increment_metric(category, key, amount)`:** Same as log_metric but increment in the in-memory dict.
  9. **`finalize(status)`:** Call `update_pipeline_run(conn, self._run_id, {status, completed_at, duration_seconds})`.
