<task type="auto">
  <name>Task 1: Create google_sheets_reader.py module</name>
  <files>google_sheets_reader.py, .env.example</files>
  <action>
Create google_sheets_reader.py with a single public function `fetch_form_submissions(conn)` that:

1. Reads GOOGLE_SHEET_ID and GOOGLE_SHEETS_API_KEY from environment (os.environ.get). If either is missing, log a warning and return {"skipped": True, "reason": "missing credentials"}.

2. Uses Google Sheets API v4 REST endpoint (no SDK needed — plain HTTP via urllib.request or aiohttp):
   - URL pattern: `https://sheets.googleapis.com/v4/spreadsheets/{SHEET_ID}/values/{RANGE}?key={API_KEY}`
   - Fetch "Missing Projects" tab: range `'Missing Projects'!A:H` (Timestamp, Name, Province, Sector, Value, Proponent, Description, Source URL, Email)
   - Fetch "Corrections" tab: range `'Corrections'!A:G` (Timestamp, Project Name, Field, New Value, Source URL, Notes, Email)

3. Track processed rows via dashboard_state key `sheets_last_processed_timestamp`. On each run:
   - Read the last processed timestamp from dashboard_state
   - Only process rows with Timestamp > last_processed (Google Forms adds timestamps in column A)
   - After processing, update the timestamp to the latest row's timestamp

4. For each new Missing Project row:
   - Call db.save_missed_project(conn, {...}) with fields mapped from Sheet columns
   - Set submitted_at to the row's timestamp
   - Set data field to JSON with any extra info (email if provided)
   - Skip rows where Source URL is empty (matches URL hard gate)

5. For each new Correction row:
   - Call db.save_missed_project(conn, {...}) with type='correction' in the data field
   - Include project_name, field_to_correct, new_value, source_url, notes in the data dict

6. Wrap all HTTP calls in try/except. On failure (network, 403, 404), log warning and return {"skipped": True, "reason": "Sheet unreachable: {error}"}. Pipeline must never crash due to Sheet issues.

7. Return a summary dict: {"processed": N, "new_projects": M, "corrections": C, "skipped_no_url": S}

Use urllib.request (stdlib) for HTTP — no new dependencies needed. Parse JSON response with json.loads().

Add GOOGLE_SHEET_ID and GOOGLE_SHEETS_API_KEY entries to .env.example (create if not exists, or append).

```python
# ── STEP 2J: Read Google Form submissions from Sheet ──────────
try:
    from google_sheets_reader import fetch_form_submissions
    sheets_result = fetch_form_submissions(conn)
    if sheets_result.get("skipped"):
        print(f"  [SHEETS] Skipped: {sheets_result.get('reason', 'unknown')}")
    elif sheets_result.get("processed", 0) > 0:
        print(f"  [SHEETS] {sheets_result['processed']} new submissions "
              f"({sheets_result.get('new_projects', 0)} projects, "
              f"{sheets_result.get('corrections', 0)} corrections)")
    else:
        print("  [SHEETS] No new submissions")
except Exception as e:
    print(f"  [SHEETS] Warning: {e}")
```
