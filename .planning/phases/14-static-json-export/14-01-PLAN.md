  <action>
Create `export_dashboard.py` with these functions:

1. `_parse_value(value_str) -> float | None` — Parses project value strings like "$1.2B", "$500M", "$2.5 billion" into float. Returns None for "Not disclosed", empty, or unparseable values.

2. `_project_for_export(proj_dict) -> dict` — Converts a db.py project dict for JSON export:
   - Parse JSON string fields (evidence, statusHistory, sources, discovery_sources, tags, anomalies) into real lists via json.loads()
   - Add `value_confirmed: bool` field — True only if _parse_value returns a non-None number
   - Include all fields the frontend needs: name, province, cma, sector, naics_code, naics_name, value, value_confirmed, status, confidence, project_type, is_brownfield, proponent, description, completionDate, firstTracked, lastUpdated, lastSeen, evidence, statusHistory, discovery_source, evidence_count, has_government_source

3. `export_province_projects(conn, province_name, threshold_val, output_dir)` — Fetches projects for a province via `get_projects(conn, province=province_name)`. For each project:
   - Parse value via _parse_value
   - If value is None (not disclosed / unparseable): include with value_confirmed=false
   - If value >= threshold_val: include with value_confirmed=true
   - If value < threshold_val: EXCLUDE
   - Write to `{output_dir}/projects_{slug}.json` where slug = province_name.lower().replace(" ", "_")

4. `export_briefings(conn, output_dir)` — Write briefing_latest.json (from get_latest_briefing) and briefing_archive.json (from get_briefing_archive, metadata only: week_of, headline, word_count, generated_at — no full sections for archive entries)

5. `export_indicators(conn, output_dir)` — Write indicators.json from get_latest_indicators(conn). Also export statcan_latest from get_dashboard_state(conn, 'statcan_latest').

6. `export_trends(conn, output_dir)` — Write trends.json from get_trend_snapshots(conn)

7. `export_events(conn, output_dir)` — Write events.json from get_upcoming_events(conn=conn, days_ahead=30)

8. `export_microscope(conn, output_dir)` — Write microscope.json from get_dashboard_state(conn, 'microscope_history')

9. `export_timeseries(conn, output_dir)` — Write timeseries.json as a single bundled object keyed by series_name. Fetch each known series via get_timeseries(conn, name, limit=52). Known series list: boc_rate, tsx_composite, comm_wti, comm_brent, comm_natgas, comm_gold, comm_silver, comm_copper, comm_aluminum, comm_wheat, idx_sp500, idx_djia, idx_nasdaq (include full list from interfaces above).

10. `export_all(conn=None, output_dir="docs/data")` — Main entry point:
    - If conn is None, create via get_db()
    - Create output_dir (os.makedirs exist_ok=True)
    - Call all export functions above
    - Write manifest.json with: exported_at (ISO timestamp), province_count, file_list (all filenames written)
    - Print summary: "[EXPORT] Wrote N files to docs/data/"
    - Return dict with file count and output_dir

11. `if __name__ == "__main__"` block — Call export_all() for standalone use

Use compact JSON formatting (no indent) for province files (can be large). Use indent=2 for briefing, manifest, and other smaller files for readability. Use ensure_ascii=False for proper French characters in Quebec project names.

Also create `tests/test_export_dashboard.py` with the behavior tests listed above. Use an in-memory SQLite database via init_db(":memory:") for test isolation. Insert test fixtures using db.py's upsert_project and save functions.
