  <how-to-verify>
The user must complete these steps in order:

**Step 1: Push code to GitHub**
Ensure all changes from Plan 16-01 are committed and pushed to the main branch.

**Step 2: Enable GitHub Pages**
1. Go to your GitHub repository in a browser
2. Click Settings (gear icon)
3. In the left sidebar, click Pages
4. Under "Source", select "Deploy from a branch"
5. Under "Branch", select "main" and folder "/docs"
6. Click Save
7. Wait 1-2 minutes for the initial deployment

**Step 3: Add repository secrets**
1. In Settings, click "Secrets and variables" in the left sidebar
2. Click "Actions"
3. Click "New repository secret" and add each:
   - Name: ANTHROPIC_API_KEY, Value: (your Anthropic API key)
   - Name: GEMINI_API_KEY, Value: (your Google AI / Gemini API key)
   - Name: TAVILY_API_KEY, Value: (your Tavily API key)

**Step 4: Verify the live site**
1. Visit your GitHub Pages URL: https://{username}.github.io/{repo-name}/
2. Confirm the dashboard loads with data
3. Check that province filter, project cards, charts, and briefing sections work

**Step 5: Test a workflow manually (optional)**
1. Go to the Actions tab in your repository
2. Click "Daily Indicators" workflow
3. Click "Run workflow" -> "Run workflow" (on main branch)
4. Watch the run complete (should take ~2-5 minutes)
5. Verify docs/data/ files are updated in the repository
