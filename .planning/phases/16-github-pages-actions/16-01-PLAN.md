  <files>deploy_to_github.py, .github/workflows/weekly-pipeline.yml, .github/workflows/daily-indicators.yml, .gitignore</files>
  <action>
Create deploy_to_github.py that:
- Copies public/index.html to docs/index.html
- Copies public/404.html to docs/404.html
- Copies public/js/ directory to docs/js/ (currently just app.js)
- Does NOT touch docs/data/ (export_dashboard.py manages that directory)
- Uses shutil.copytree with dirs_exist_ok=True for the js directory
- Uses shutil.copy2 for individual files
- Prints what it copied (e.g., "Copied public/index.html -> docs/index.html")
- Is idempotent (safe to run repeatedly)
- Has a __main__ guard so it can be run standalone or imported

Create .github/workflows/weekly-pipeline.yml:
- name: "Weekly Pipeline"
- on.schedule: cron "30 10 * * 1" (5:30 AM ET = 10:30 UTC, Monday)
- on.workflow_dispatch (manual trigger)
- runs-on: ubuntu-latest
- Steps:
  1. actions/checkout@v4 with token: ${{ secrets.GITHUB_TOKEN }}
  2. actions/setup-python@v5 with python-version: "3.12"
  3. pip install -r requirements.txt
  4. Run pipeline: python update_dashboard.py
     env: ANTHROPIC_API_KEY, GEMINI_API_KEY, TAVILY_API_KEY from secrets
     Also set: GEMINI_MODEL=gemini-2.5-flash, SONNET_MODEL=claude-sonnet-4-6, GEMINI_SEARCH_ENABLED=false
  5. Run deploy: python deploy_to_github.py
  6. Commit and push: git add docs/ && git diff --staged --quiet || (git commit -m "auto: weekly pipeline update $(date +%Y-%m-%d)" && git push)
     Use git config for github-actions bot identity

Create .github/workflows/daily-indicators.yml:
- name: "Daily Indicators"
- on.schedule: cron "0 5 * * *" (midnight ET = 5:00 UTC)
- on.workflow_dispatch (manual trigger)
- runs-on: ubuntu-latest
- Steps: Same as weekly but step 4 runs: python update_dashboard.py --indicators-only
  Same env vars from secrets
  Step 5: python deploy_to_github.py
  Step 6: Same commit/push pattern with message "auto: daily indicators $(date +%Y-%m-%d)"

IMPORTANT for both workflows:
- The checkout step needs: fetch-depth: 0 (so git push works)
- Configure git user: git config user.name "github-actions[bot]" and git config user.email "github-actions[bot]@users.noreply.github.com"
- The commit step must handle "nothing to commit" gracefully (use git diff --staged --quiet || ...)
- Both workflows need permissions: contents: write

Update .gitignore to add these entries if not present:
- .env
- *.db (dashboard.db, pipeline cache)
- serviceAccountKey.json
- __pycache__/
- .cache/
  </action>
